# 12 — Dashboard UI

## Instructions

Copy `assets/dashboard.html` → `ui/index.html` verbatim.

Do not modify the HTML file. It is a complete self-contained dashboard that:
- Polls `/api/stats?range=<N>` every 5 seconds
- Renders with mock data when the API is unreachable (safe for dev)
- Shows: total requests, success/escalation/error rates, model distribution,
  task types, latency histogram + P50/P90/P99, escalation flow, recent requests table
- Supports time range switching: last 50, last 200, 1h, 6h, today, all time

## Wiring in main.py

```python
from fastapi.staticfiles import StaticFiles

# After app = FastAPI(...)
app.mount("/ui", StaticFiles(directory="ui", html=True), name="ui")
```

## Verify

After `uvicorn main:app --port 8765`:
- `curl http://localhost:8765/optmod/status` → JSON status
- Open `http://localhost:8765/ui` → dashboard loads in browser
- Dashboard shows "live" green dot when connected, "disconnected" red dot when not
